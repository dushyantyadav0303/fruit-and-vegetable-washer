## About the Project


**Fruit and Vegetable washer** - It is a Washer that Clean the Vegetables/Fruits using Water pressure. Water apply force on Fruit which make them spin and Clean


## Repository Structure
- `src/`  Blender project sources
- `production/` Production File
- `Render/` for Render Sources

### Recommended Print Specifications


> [!TIP]
> FDM Printing is More than Enough.
> If you want premium Finishing then Apply Epoxy Resin Coat.

| Specification | Default Value / Range |
| :--- | :--- |
| **Printer Nozzle** | 0.4 mm Stainless Steel |
| **Layer Height** | 0.2 mm |
| **First Layer Height** | 0.2 mm |
| **Nozzle Temperature** | Depends on your Filament |
| **Build Plate Temperature** | Depends on your Filament |
| **Sparse Infill Density** | 10% |
| **Max Toolhead Speed** | 500 mm/s |
| **Max Acceleration** | 8000 mm/s² |
| **Support**  | ON |

 source: `Production`
